# C6 중고 PC 사냥꾼 (used-pc-judge)

한국 중고 시장(당근, 중고나라, 번개장터, 퀘이사존 장터)의 **데스크탑 PC 매물 글**을 붙여넣으면

1. **A5 적정가 판정** - 글에서 CPU/GPU/램/저장장치/파워/보드/쿨러/가격/보증/위험 신호를 뽑아 부품 시세표로 적정가 범위를 계산하고 `싸다 / 적정 / 비싸다 / 의심` 으로 판정합니다. 이유를 한 줄씩 보여주고, 판매자에게 물어볼 질문과 복사해서 보낼 메시지 템플릿을 만들어 줍니다.
2. **A6 업그레이드 추천** - "이거 사서 이거만 바꾸면 이 예산에 이 성능" 을 계산합니다. (`게임 1440p`, `로컬 LLM 30B`, `영상편집` ...)
3. **비교 모드** - 매물 여러 개를 가성비 점수 순으로 줄 세웁니다.

Python 3.9+ 표준 라이브러리만 씁니다 (설치할 것 없음). 출력은 한국어 콘솔용 텍스트이고 `--md` 로 Markdown 리포트도 저장합니다.

> ## 먼저 읽으세요: 가격표는 임시 추정치입니다
>
> `prices/parts_used_kr.json` 에 들어 있는 가격은 **작성자가 거래완료 시세를 조사하지 않고 대충 잡은 ROUGH PLACEHOLDER** 입니다.
> 실제 시세가 아니고, 몇 달만 지나도 크게 틀립니다 (특히 램, 그래픽카드).
> 이 도구의 판정은 **전적으로 가격표에 의존**하므로, 쓰기 전에 직접 갱신하세요 ([가격표 관리](#가격표-관리) 참고).
> 가격표가 임시값이거나 기준일이 45일 넘게 지나면 모든 출력 맨 위에 경고가 뜹니다.

## 사이트 이용약관 / 스크래핑

**크롤링·스크래핑 코드는 없습니다.** 네트워크 요청은 (사용자가 직접 켠 경우) 로컬 LLM 서버 호출뿐입니다.
매물 글은 사용자가 사이트에서 **복사해서 파일에 붙여넣습니다** (제목 + 본문, 또는 URL 페이지의 복사한 텍스트).

## 빠른 시작

```bash
cd used-pc-judge

# 1. 매물 글을 파일로 저장 (제목 + 본문 붙여넣기)
cat > listing.txt   # 또는 에디터로 작성. 예제: examples/listing_sample.txt

# 2. 판정
python -m usedpc judge listing.txt

# 3. 이 매물을 산 뒤 업그레이드까지 (예산 150만원 = 매물가 + 교체 비용)
python -m usedpc judge listing.txt --use "로컬 LLM 30B" --budget 150
python -m usedpc judge listing.txt --use "게임 1440p" --budget 120 --md report.md

# 4. 여러 매물 비교: 파일 안에서 '---' 한 줄로 구분
python -m usedpc compare listings.txt --md compare.md

# 5. 가격표 보기/수정
python -m usedpc prices show gpu
python -m usedpc prices set "RTX 4070 Super" 68만
python -m usedpc prices stamp
```

표준입력도 됩니다: `pbpaste | python -m usedpc judge -` (파일 인코딩은 UTF-8 우선, 실패하면 CP949).
Windows 콘솔에서 글자가 깨지면 Windows Terminal을 쓰거나 `chcp 65001` 을 먼저 실행하세요.

### 명령 요약

| 명령 | 설명 |
|---|---|
| `judge FILE` | 매물 1개 판정. `-` 는 표준입력. `--use`, `--budget`(만원), `--md OUT.md`, `--no-questions` |
| `compare FILE` | `---` 로 구분된 여러 매물을 순위표로. `--md` 지원 |
| `prices show [섹션]` | 가격표 출력 (`gpu`, `cpu`, `board`, `ram_per_gb`, `adjust` ...) |
| `prices set <부품> <가격>` | 가격 수정. `85만` / `850000` / `85`(=85만원) / `850k`. 신품 기준가는 `--new`. `ram_per_gb.DDR4 3000` 처럼 점 표기도 가능(이때 숫자는 원) |
| `prices stamp` | 기준일(as_of)을 오늘로 하고 placeholder 표시를 끔 (`--keep-placeholder` 로 표시 유지) |

공통 옵션: `--prices 경로`(가격표 지정, 또는 환경변수 `USEDPC_PRICES`), `--today YYYY-MM-DD`(테스트용 기준일), `--llm`(아래 참고).

## 판정 방식

```
부품 합계(시세표)
  - 채굴 GPU 할인 / 리퍼 / 불량 가정 감가
  x 완본체 보정 (기본 0.93, 브랜드 PC 0.80)
  - 사용 연수 감가 (3년 초과분 연 3%, 최대 15%)
  + 남은 무상 보증 (월 0.4%, 최대 6%, 영수증 +1%)
  - 박스 없음 / 무명 파워 교체비 / 쿨러 소음 교체비
  + 번들 모니터·주변기기 (중고 가치)
= 적정가 중앙값 -> 범위 (기본 +-8%, 추정 항목이 많을수록 넓어짐, 최대 +-30%)
```

- 글에 없는 부품(보드/파워/케이스/쿨러/램/저장장치)은 **가정값**으로 채우고 "(가정)" 으로 표시하며 범위를 넓힙니다.
- 판정: 범위 안이면 `적정`, 아래면 `싸다`, 위면 `비싸다`.
  - **`의심`**: (a) 사기 신호가 겹칠 때(직거래라면서 선입금/예약금 요구, 외부 결제 링크, 안전결제 거부+외부 메신저+과장 문구 등), (b) 가격이 범위 하한의 65% 미만(너무 쌈), (c) "시세보다 너무 싸다" 문구 + 시세 이하 가격.
  - `판단불가`: 판매가를 못 찾음 / CPU·그래픽카드 정보 없음 / 노트북 / 가격표에 없는 부품. 이때도 적정가 범위가 계산되면 참고용으로 보여줍니다.
  - 부팅 불량·부품용은 "고장품" 가정으로 -45% 계산하며 사기 의심과 구분합니다.
- 모든 계수(`adjust` 섹션)는 가격표 JSON에서 고칠 수 있습니다.
- 단품(그래픽카드만 등) 매물은 완본체 보정 없이 그 부품 시세와만 비교합니다.

### 판매자 질문

빠진 정보와 위험 신호별로 질문을 만들고 우선순위(필수/권장/참고)를 붙입니다. 예: `혹시 파워 브랜드/모델 알 수 있을까요?`, `채굴 이력이 있다고 보이는데 ...`, `직거래로 만나서 현장 확인 후 결제하고 싶습니다. 선입금/예약금 없이 가능한가요?`.
필수·권장 질문은 번호가 매겨진 메시지 템플릿으로 묶여 나옵니다 (그대로 복사해서 채팅에 붙여넣기).

## 업그레이드 추천

`--use` 와 `--budget`(총 예산, 만원) 을 주면 매물 가격 + 교체 비용이 예산 안에 들어오는 조합을 최대 2개 제안합니다.

```
이 매물 600,000원 + RX 7900 XT로 교체(차액 439,600원) + 800W 80+ Gold급 파워로 교체(차액 35,625원) → 총 1,075,225원, 신품 대비 23% 절약
```

- **차액** = 새 부품 중고 시세 - 기존 부품 중고 시세 x 0.93 (기존 부품을 되판다고 가정, 수수료·감가 반영). 되팔지 않으면 차액이 아니라 전액이 듭니다.
- **신품 대비 절약** = 같은 최종 구성을 신품으로 샀을 때(시세표 `new` 값, 없으면 중고가/0.7)와 비교한 대략치.
- 추천 1은 "목표를 충족하는 최소 비용", 추천 2는 "예산 안 최대 성능" 입니다. 이미 목표를 충족하면 교체가 필요 없다고 알려줍니다.
- 용도: `게임 1080p/1440p/4K`, `로컬 LLM 30B`(모델 크기 + 선택적 양자화 `q8`; VRAM 필요량 = 파라미터 x 0.57GB(Q4) + 오버헤드), `영상편집`, `스테이블 디퓨전`.
- 후보 교체는 GPU, 같은 소켓의 CPU, RAM 용량이며 둘을 묶은 조합도 봅니다. 파워가 모자라지면 파워 교체 비용을 자동으로 포함합니다.
- **병목/호환 메모**: CPU-GPU 균형(해상도별), 파워 용량 충분 여부와 무명 파워 경고, PCIe 세대(x8 카드가 PCIe 3.0 보드에 꽂힐 때), RAM DDR4/DDR5 플랫폼과 업그레이드 한계(AM4 마지막은 5700X3D/5800X3D 등), BIOS 업데이트 필요, 싱글 채널, LLM은 VRAM 여유·AMD 런타임 호환.
- 성능 등급표는 `usedpc/catalog.py` 의 대략적인 상대 지수(GPU: RTX 4070=100, CPU: 7800X3D=100)입니다. 벤치마크가 아닙니다.

## 비교 모드

`---` 한 줄로 매물을 구분한 파일을 넣으면 순위표를 만듭니다.
점수 = 적정가 중앙값 / 판매가 x 100 - 위험 신호 감점 (100 = 적정, 높을수록 이득). `의심`은 점수와 무관하게 아래로, `판단불가`는 맨 아래로 내려갑니다. 성능 지수와 만원당 성능도 함께 보여 줍니다.

## 로컬 LLM (선택)

규칙 파서가 놓친 필드(빈칸 또는 신뢰도 0.7 미만)만 로컬 LLM으로 채웁니다. **규칙이 확실하면 규칙이 이깁니다** (충돌은 메모로 남김). 규칙이 충분히 확신하면 호출 자체를 생략합니다.

```bash
# LM Studio / llama.cpp server / Ollama 등 OpenAI 호환 서버
export USEDPC_LLM_URL=http://127.0.0.1:1234/v1
export USEDPC_LLM_MODEL=내-모델-이름
python -m usedpc judge listing.txt --llm
```

- 기본적으로 **localhost/사설 IP 주소만 허용**합니다 (매물 글이 외부로 나가지 않게). 외부 서버는 `--allow-remote`.
- 매물 글은 "데이터"로만 취급하도록 프롬프트에 명시하고, LLM 출력은 카탈로그에 대해 다시 검증합니다 (없는 모델·말이 안 되는 값은 버림). LLM이 실패하거나 JSON을 못 만들어도 규칙 결과로 계속 진행합니다.
- 이 저장소의 테스트는 가짜 클라이언트만 쓰고 네트워크를 쓰지 않습니다.

## 가격표 관리

1. 당근/중고나라/번개장터/퀘이사존 장터에서 **거래완료(판매완료) 표시가 있는 글**의 최종 가격을 직접 봅니다. 호가(올려놓은 가격)는 시세가 아닙니다.
2. 같은 부품의 거래완료 가격 3~5개의 중간값을 잡아 반영합니다.
   ```bash
   python -m usedpc prices set "RTX 4070 Super" 68만
   python -m usedpc prices set 12400f 9.5만
   python -m usedpc prices set B660 9만
   python -m usedpc prices set ram_per_gb.DDR4 2200        # 램은 GB당 원
   python -m usedpc prices set "RTX 4090" 300만 --new      # 신품 기준가(절약률 계산용)
   ```
   또는 `prices/parts_used_kr.json` 을 에디터로 직접 고쳐도 됩니다 (원 단위 정수).
3. 한 번에 다 갱신했으면 `python -m usedpc prices stamp` 로 기준일을 오늘로 바꾸고 placeholder 표시를 끕니다.
4. 램·그래픽카드는 변동이 크니 **최소 한 달에 한 번**은 확인하세요. 기준일이 45일(`adjust.stale_days_warn`) 넘으면 경고가 뜹니다.
5. 새 부품이 카탈로그에 없으면 (`usedpc/catalog.py` 의 표에 한 줄 추가 + JSON에 가격 추가) 인식됩니다. 카탈로그에 없는 CPU 모델은 같은 패밀리의 가장 가까운 모델로 근사하고 "근사"로 표시합니다.

## 한계

- **가격표 정확도가 곧 판정 정확도**입니다. 배포 값은 임시 추정치입니다.
- 부품 합산 방식이라 브랜드 완제품, 올인원, 미니 PC, 노트북은 정확하지 않거나 판정하지 않습니다.
- 글에 없는 정보는 가정으로 채우므로 범위가 넓어집니다. 사진에만 있는 정보(모델명 스티커, 시리얼, 외관)는 읽지 못합니다.
- 규칙 파서는 흔한 표기 위주입니다. 이상한 줄임말·오타는 놓칠 수 있고(그때는 `--llm` 또는 판매자 질문), 반대로 잘못 해석할 수도 있습니다. **인식 결과를 눈으로 한 번 확인하세요** ("인식한 구성" 표).
- 사기 의심 판정은 문구 패턴과 가격만 보는 휴리스틱입니다. `의심` 이 아니라고 안전한 것이 아니고, `의심` 이라고 반드시 사기인 것도 아닙니다.
- 성능 지수와 병목 진단은 단순화한 등급표입니다 (게임별·옵션별 차이, 레이트레이싱, 실제 LLM 토큰 속도 등은 반영하지 않음).
- 시세는 지역/시기/성수기에 따라 달라지고, 보증 남은 제품·풀박스 프리미엄은 단순 계수로만 반영합니다.
- 이 도구는 법률/금융 조언이 아니며 거래 결과에 책임지지 않습니다.

## 중고 거래 안전 팁

**결제**
- 가능하면 **플랫폼 안전결제**(당근페이/번개페이/네이버페이 안전결제 등)를 쓰세요. "수수료 아깝다", "안전결제 불가" 는 위험 신호입니다.
- 직거래인데 **예약금/선입금**을 먼저 요구하면 거의 사기입니다. 만나서 확인한 뒤에 결제하세요.
- 텔레그램/외부 메신저/외부 링크로 옮기자고 하거나 입금 링크를 보내면 대화를 끊으세요.
- 시세보다 확 싼 급처는 이유를 꼭 확인하세요. 계좌는 거래 전에 더치트 등에서 조회하세요.
- 본인 소유인지 확인하세요 (대리 판매, 지인 물건 주의): 구매내역, 시리얼 사진, 본인 인증 메모 사진.

**직접 만나서 확인 체크리스트** (사용 가능한 모니터/키보드를 가져가세요)
- [ ] 스펙 일치: CPU-Z / GPU-Z / 작업관리자로 CPU, GPU(VRAM), 램 용량·클럭(XMP/EXPO 켜졌는지), 저장장치 확인
- [ ] 부팅: 전원 버튼부터 윈도우 진입까지 정상인지, 재부팅 반복·블루스크린 없는지
- [ ] 벤치: 3DMark / Cinebench / FurMark 5~10분 - 크래시, 아티팩트(화면 깨짐), 클럭 급락 없는지
- [ ] 온도: CPU/GPU 부하 온도와 팬 소음, 코일 울음. 써멀 상태가 나쁘면 재도포 비용 고려
- [ ] 외관: 케이스 찍힘, GPU 백플레이트/팬 상태, 보조전원 포트 그을림·변형, 먼지·담배 냄새, 램/보드 슬롯 상태
- [ ] 시리얼: GPU/CPU/보드/파워 시리얼과 영수증·제조사 보증 조회(AS 기간) 일치 여부
- [ ] 저장장치 건강: CrystalDiskInfo 상태, 총 기록량(TBW), 재할당 섹터
- [ ] 파워: 브랜드/모델/용량 스티커 확인 (무명 파워면 교체 비용을 가격에서 빼기)
- [ ] 채굴 흔적: 바이오스 수정, 비정상적으로 낡은 팬, 영상출력 포트 마모, 사용 기간 대비 과한 마모
- [ ] 구성품: 박스, 케이블, 브래킷, 윈도우 라이선스 여부
- [ ] 거래 기록: 채팅 캡처, 판매자 연락처/계좌 확인. 현금 직거래는 영수증 대신 메모 사진이라도 남기기

## 테스트

```bash
cd used-pc-judge
python3 -m unittest discover -s tests -v
```

합성 한국어 매물 25종(`tests/fixtures.py`)과 단위 테스트가 파싱, 가격 파싱, 적정가 계산, 위험 신호, 질문 생성, 업그레이드, 비교, LLM 병합(가짜 클라이언트), CLI/가격표 편집을 검증합니다.
테스트는 배포용 가격표를 복사한 뒤 일부 값을 고정해서 쓰므로, `prices/parts_used_kr.json` 을 갱신해도 깨지지 않습니다.

## 파일 구조

```
usedpc/
  __main__.py, cli.py     명령줄 (judge / compare / prices)
  aliases.py              은어·약어 치환, 한글 숫자 읽기, 텍스트 정규화
  catalog.py              부품 카탈로그 (정식 이름, 소켓, VRAM, 전력, 성능 지수)
  parts_parser.py         CPU/GPU/RAM/저장장치/파워/보드/쿨러/모니터 추출
  listing_info.py         가격, 보증, 연식, 매물 종류, 위험·긍정 신호
  parser.py               파싱 진입점 (+ '---' 분리)
  prices.py               가격표 로드/조회/수정
  judge.py                적정가 계산과 판정
  questions.py            판매자 질문과 메시지 템플릿
  upgrade.py, perf.py     업그레이드 추천, 성능 등급, 용도 해석
  compare.py              여러 매물 순위
  llm.py                  선택적 로컬 LLM 보충과 병합
  report.py, textutil.py  콘솔/Markdown 출력
prices/parts_used_kr.json 임시 추정치 가격표 (직접 갱신!)
examples/                 샘플 매물 글
tests/                    unittest
```
