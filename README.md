## 공통 기반 (jjkit)

- 새 프로젝트: `python tools/new_project.py <폴더> --modules llm,notify`
- 복사본 갱신: `python tools/jjkit_sync.py <폴더>`
- CI 검사(모든 복사본이 원본과 같은지): `python tools/jjkit_sync.py --check-all`
- 각 프로젝트의 `_jjkit/`는 직접 고치지 않습니다. 고칠 때는 `jjkit/`에서 고친 뒤 동기화합니다.

## 테스트

- 전체 테스트 실행: `python run_all_tests.py` (`tests/` 폴더가 있는 모든 프로젝트를 실행하고 요약 표를 출력합니다)
- 일부만 실행하거나 제외: `--only a,b`, `--skip a,b`, 첫 실패 시 중단: `--fail-fast`
- CI(GitHub Actions)는 push와 PR마다 Ubuntu / Windows × Python 3.12 / 3.14 조합에서 테스트를 실행합니다.

## 공통

- 모든 프로젝트는 Python 3.12+ 표준 라이브러리만 사용합니다 (외부 패키지 없음). 테스트는 Python 3.12 / 3.14에서 확인합니다.
